# Apps not managed by Homebrew

Generated by `./dump-packages.sh` (the "MANUAL" section), then annotated by hand.
Everything else lives in [Brewfile](Brewfile) — restore with `brew bundle install`.

## Manually downloaded, a cask exists

These were installed from a .dmg/.pkg. To let Homebrew adopt one without
reinstalling: `brew install --cask --adopt <token>`.

Most of them self-update (Sparkle or a built-in updater), which is why they were
never brewed. Adopting is only worth it for the one-command restore on a new Mac.

| App | Cask token | Self-updates |
|---|---|---|
| AnyDesk | `anydesk` | yes |
| Claude | `claude` | yes |
| DBeaver | `dbeaver-community` | yes |
| Ghostty | `ghostty` | yes (Sparkle) |
| GitHub Desktop | `github` | yes |
| Google Chrome | `google-chrome` | yes |
| Logi Options+ | `logi-options-plus` | yes |
| Ollama | `ollama` | yes |
| Raycast | `raycast` | yes |
| Telegram | `telegram` | yes |
| Visual Studio Code | `visual-studio-code` | yes |
| Windows App | `windows-app` | yes |
| Яндекс Музыка | `yandex-music` | yes |
